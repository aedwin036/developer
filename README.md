Este es mi portafolio web personal, desarrollado con HTML, CSS y JavaScript, donde presento mi perfil, proyectos y formas de contacto de manera clara, moderna y responsive.
El objetivo del proyecto es mostrar mis habilidades en desarrollo frontend y buenas prácticas de diseño web.


🚀 Características principales

✅ Navegación mediante navbar con secciones:
Inicio
Sobre mí
Contacto
Blog

✅ Cada sección cuenta con imágenes representativas

✅ Banner principal en la sección Inicio

✅ Diseño responsive (adaptable a móviles, tablets y PC)

✅ Navegación fluida sin scroll innecesario

✅ Scroll solo cuando el contenido lo requiere

✅ Sección de contacto funcional vía WhatsApp

✅ Interfaz limpia y enfocada en la experiencia del usuario


🛠️ Tecnologías utilizadas
HTML5 – Estructura del sitio
CSS3 – Diseño, estilos y responsive layout
JavaScript – Interactividad y navegación dinámica

📱 Contacto
Desde la sección Contacto, es posible comunicarse directamente conmigo a través de WhatsApp, facilitando una comunicación rápida y directa.
